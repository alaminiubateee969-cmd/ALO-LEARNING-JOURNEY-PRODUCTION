# 18. EXPLICIT DURATION TOLERANCE

Define:

R = requested duration in seconds

A = actual duration

D = A - R

E = abs(D) / R

Default tolerance:

allowedTolerance =
min(
max(R × 0.02, 2),
5
)

Therefore:

50 sec → ±2 sec tolerance
60 sec → ±2 sec
120 sec → ±2.4 sec
300 sec → ±5 sec
600 sec → ±5 sec
1800 sec → ±5 sec
3600 sec → ±5 sec

BUT the product minimum overrides undershoot tolerance for the minimum request.

For requested 50 seconds:

A MUST be >= 50 seconds.

Therefore:

Requested = 50
Actual = 49.5

MUST FAIL.

Requested = 50
Actual = 50

PASS.

Requested = 50
Actual = 51.5

PASS.

Requested = 50
Actual = 52.1

FAIL if outside configured maximum overshoot tolerance.
